# 하이파이브(High5) 전체 기능 리스트 + 역할별 권한 + 사이트맵 v1

> 작성일 2026-09-07 · 근거: 현재 `main` 브랜치 실제 코드(`src/middleware.ts`, `src/components/AppHeader.tsx`, 각 페이지/`src/app/api/**`) 직접 확인
> 역할: `SUPERADMIN`(플랫폼 운영자) / `ADMIN`(조직 관리자) / `LEADER`(리더) / `WORKER`(작업자)

---

## 1. 역할 개요

| 역할 | 범위 | 성격 |
|---|---|---|
| `SUPERADMIN` | 플랫폼 전체(모든 조직) | 서비스 운영자. 조직 생성/plan 관리/전체 통계, 조직 내부 업무에는 관여하지 않음 |
| `ADMIN` | 소속 조직 전체 | 조직 관리자. 팀원/프로젝트/설정/통계 전권 |
| `LEADER` | 소속 조직 (팀원관리 제외) | 업무 배정/결재/통계 조회 가능, 계정 관리는 불가 |
| `WORKER` | 소속 조직 (제한적) | 배정된 업무 수행, 신청/위키/회의록 등 협업 기능 이용 |

```

/{slug}/wiki                   인증 — 위키 허브 (전 역할)

/{slug}/announcements          인증 — 공지사항 (조회 전 역할, 작성은 ADMIN·LEADER)
/{slug}/inquiries              인증 — 문의 관리 (ADMIN, LEADER)
/{slug}/my-notes               인증 — 개인 자료 보관 (전 역할, 본인 것만)
/{slug}/manual                 인증 — 사용 매뉴얼 (전 역할)
/{slug}/profile/password       인증 — 비밀번호 변경 (전 역할)
/{slug}/settings/security      인증 — 2FA·세션 관리 (전 역할, 본인 계정)
/{slug}/settings/organization  인증 — 조직 정보 설정 (ADMIN)
/{slug}/settings/ai            인증 — AI 기능 설정(API 키/토글) (ADMIN)
/{slug}/settings/integrations  인증 — 외부연동(Slack 등) 설정 (ADMIN)

/{slug}/settings/audit         인증 — 감사 로그 (ADMIN, LEADER)
```

## 4. 기능 리스트 (도메인별)

### 4-1. 인증/계정
- 이메일+비밀번호 로그인(조직별 슬러그 로그인 / SUPERADMIN 전용 로그인 분리)
- 2단계 인증(TOTP) 설정/해제
- 세션(디바이스) 목록 조회 및 개별 종료
- 비밀번호 변경
- 조직 공개 가입(`/register`) — 이용약관/개인정보처리방침 동의 필수

### 4-2. 업무 관리
- 업무 등록/수정/삭제, RMS 번호 자동 파싱
- 그룹 업무(하위 업무 포함), 라벨(긴급/주말대응/비상), 우선순위
- 프로젝트별 커스텀 상태 단계(칸반), 커스텀 필드(자유 속성)
- 자동 시간 카운트, 댓글/대댓글, 첨부파일, 체크리스트
- 업무 히스토리(변경 이력), CSV/Excel 내보내기
- 업무 출처 추적(직접등록/홈페이지 문의전환)
- GitHub PR/이슈 연동(webhook)

### 4-3. 프로젝트
- 프로젝트 생성/수정/종료/재개, 멤버 관리
- 프로젝트 개요, PM 지정, 자유 역할 리스트(기획/디자인/개발/시장조사 등 자유 입력)
- 위키 사용여부/간편모드 스위치(프로젝트별)
- 프로젝트 위키(멤버 전용 문서), 회의록(액션아이템 관리, AI 요약)

### 4-4. 협업
- 신청(휴가/비품) + 결재/전결
- 공지사항(배너)
- 정보(FAQ)
- 개인 메모 스티커, 개인 자료 보관(my-notes)
- 홈페이지 문의 접수(공개 폼) → 검토 → 업무 전환
- 전역 검색

### 4-5. 알림/외부연동
- 인앱 알림(담당자/상태변경/문의접수 등), 업무·프로젝트 단위 알림 음소거
- Slack/잔디/Teams/텔레그램/카카오톡 웹훅 연동
- 구글 캘린더 연동(개인 구독)
- 이메일 발송(가입 환영/문의 접수 확인 등)

### 4-6. AI 자동화 (조직별 API 키 등록 시 활성화)
- 업무 초안 작성, 업무 요약, 자연어 검색
- 주간 보고서, 담당자별 업무 부하 인사이트
- 회의록 자동 요약, 날씨 인사말

### 4-7. 통계/감사
- 통계 대시보드(완료율, 부하량 등)
- 감사 로그(조직 내 주요 변경 이력)

### 4-8. 플랫폼 관리(SUPERADMIN)
- 조직 생성/plan 변경/활성화·비활성화/삭제
- 조직별 사용자 직접 추가
- 플랜별(FREE/PRO/ENTERPRISE) 메뉴 노출 설정
- 무료 데모 신청 접수/관리
- 플랫폼 전체 통계
