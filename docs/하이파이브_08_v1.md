## 1. 개요

**하이파이브(High5)**는 소규모~중견 조직을 위한 경량 SaaS 업무관리·협업 플랫폼이다. 여러 회사(조직)가 각자 고유한 URL 슬러그로 가입해 독립된 데이터 공간에서 사용하는 **멀티테넌시 구조**이며, 플랫폼 운영자(SUPERADMIN)가 전체 조직을 관리한다.

| 항목 | 내용 |
|---|---|
| 제품 성격 | 지라만큼 편리하고 노션만큼 자유롭되 복잡하지 않은 내부 업무관리 콘솔 |
| 기술 스택 | Next.js 15(App Router) · Prisma 5 · PostgreSQL · NextAuth.js 4(JWT) · Zustand · MUI |
| 배포 | Railway (`railway.json`, `postbuild`로 관리자 계정 upsert) |
| 아키텍처 | 멀티테넌시 — 거의 모든 핵심 테이블에 `organizationId` 보유 |

## 2. 사용자 · 조직 구조

### 2.1 역할 체계

| 구분 | 역할 코드 | 범위 | 설명 |
|---|---|---|---|
| 플랫폼 운영자 | `SUPERADMIN` | 전체 조직 | `/superadmin`에서 조직 생성/plan 변경/사용자 추가, 모든 보호 라우트 통과 |
| 조직 관리자 | `ADMIN` | 소속 조직 전체 | 조직 내 전체 기능 + 사용자관리 |
| 리더 | `LEADER` | `/users` 제외 전체 | 업무 생성/배정, 검수, 통계 조회, 공지 작성, 결재/전결 |
| 작업자 | `WORKER` | `/stats`, `/users` 제외 | 배정된 업무 수행, 신청 작성 |

### 2.2 조직 가입 & 로그인

- **공개 가입**(`/register`, `POST /api/organizations`): 회사명·슬러그·관리자 이름/이메일/비밀번호를 입력하면 `Organization` + `ADMIN` 계정이 동시에 생성된다. 슬러그 중복, 이메일 중복, 비밀번호 8자 이상을 서버에서 검증.
- **조직별 로그인**(`/{slug}/login`, `GET /api/organizations/[slug]`로 조직 존재 확인): 슬러그로 접근한 조직 소속 사용자만 로그인.
- **플랫폼 운영자 로그인**(`/login`): SUPERADMIN 계정 전용.
- **초대**: `InviteToken` 모델(이메일/역할/만료일)로 조직 내 사용자 초대 발급 가능(`POST /api/users/invite`, ADMIN 전용).

## 4. 핵심 기능 명세

### 4.1 업무 관리
- **등록/수정/삭제**, 제목에서 RMS 번호 자동 파싱(`/\[([A-Z]+-\d+)\]/`).
- **그룹 업무 / 하위 업무**: `Task.isGroup`, 자기참조 `parentTaskId`(`subTasks` relation). 등록 시 하위 업무 여러 건을 함께 생성하거나, 이후 `/tasks/create?parentTaskId=` 로 개별 추가 가능. 목록에서 ▶/▼ 토글로 펼침/접힘.
- **라벨**: 긴급/주말대응/비상 3종, `Task.labels`에 콤마 구분 문자열로 저장.
- **상태 전이**: 프로젝트별 커스텀 단계(`ProjectStatus` — `code`/`label`/`color`/`order`/`isProgress`/`isDone`). 프로젝트에 커스텀 단계가 없으면 기본 5단계(ASSIGNED→PROGRESS→REVIEW→QA→DONE)를 그 자리에서 합성해 폴백 — 별도 마이그레이션 없이 기존 프로젝트가 그대로 동작.
- **자동 시간 카운트**: `timeCounterEnabled=true`인 업무는 `isProgress` 단계 진입/이탈 시 `TimeLog`가 자동 시작/종료(`durationHours` 자동 계산, `adjustedHours`로 수동 보정 → `finalHours`).
- **댓글/대댓글**: `TaskComment`(1단계 대댓글, `parentId` 자기참조).
- **커스텀 필드**: `ProjectField`(TEXT/NUMBER/DATE/SELECT/CHECKBOX/LINK, 프로젝트당 최대 10개) + `TaskFieldValue`, 업무 목록에 프로젝트별 섹션으로 노션 스타일 컬럼 편집(추가/삭제/드래그 순서변경) 및 인라인 업무 등록 지원.
- **히스토리**: `TaskHistory`(CREATED/STATUS_CHANGED/WORKER_CHANGED/TIMER_START/TIMER_STOP/NOTE_UPDATED/TRANSFERRED).
- **내보내기**: `GET /api/tasks/export` — CSV/Excel 다운로드.
- **일괄 처리, D-day 표시**: 목표일 기준 D-day 뱃지, 다건 선택 후 상태/담당자 일괄 변경.

### 4.2 칸반 보드 (`/tasks/kanban`)
프로젝트 선택 시 해당 프로젝트의 커스텀 단계가 컬럼이 되고, "전체 프로젝트" 보기에서는 실제 사용 중인 상태 코드를 모아 동적으로 컬럼 구성. 드래그 앤 드롭으로 상태 변경.

### 4.3 프로젝트 관리
`Project`/`ProjectMember`로 멤버 구성. 프로젝트별 위키(`WikiPage`), 커스텀 상태(`ProjectStatus`), 커스텀 필드(`ProjectField`) 보유.

### 4.4 캘린더 & 통계
- **배포 캘린더**(`/calendar`): 목표일 기준 월별 업무 시각화, 승인된 휴가 신청도 함께 표시.
- **iCal 구독**: `GET /api/calendar/ical-url`로 서명 토큰 발급 → `GET /api/calendar/ical?token=`으로 `.ics` 피드 제공.
- **통계**(`/stats`, ADMIN/LEADER): 월간 완료율, 작업자별 부하량, 기간 필터.

### 4.5 위키 & 개인 자료
- **프로젝트 위키**(`/projects/[id]/wiki`): 라이트 마크다운(`**굵게**`/`*기울임*`/`- 목록`), 소속 멤버 또는 ADMIN만 조회/작성, 삭제는 작성자 본인·ADMIN.
- **위키 허브**(`/wiki`) + **통합검색**(`GET /api/wiki/search?q=`), 우하단 플로팅 검색 버튼.
- **개인 메모**(`StickyNote`, 최대 3개, 화면 가장자리 슬라이드 패널)와 **개인 자료 보관**(`UserPage`/`my-notes`, 최대 3개).
- **전역 검색**(`GET /api/search`): 업무/위키 등 통합 검색.

### 4.6 공지 & 신청/결재
- **공지**(`Announcement`): ADMIN/LEADER 작성, 헤더 하단 배너 노출, X로 닫으면 브라우저 `localStorage`에 dismiss 기록.
- **신청**(`Request`, LEAVE/SUPPLY): 전 역할 신청 가능, `managerId` 라인을 따라 결재. ADMIN/LEADER는 "공지로 등록" 체크로 결재 없이 즉시 확정 + 공지 자동 생성(전결).

### 4.7 알림 & 외부연동
- **인앱 알림**(`UserNotification`): 담당자/상태 변경 시 생성, `useNotifications` 훅이 30초 폴링으로 감지해 토스트 표시.
- **외부연동**(`Integration`, ADMIN 전용 `/settings/integrations`): Slack/잔디/Microsoft Teams/텔레그램/카카오톡 채널별 Webhook URL(또는 텔레그램 봇 토큰) 저장 + 테스트 발송. DB 저장값이 `.env` 값보다 우선.
- **GitHub 연동**: `Task.externalLink`에 등록한 PR이 머지되면 webhook(서명 검증)이 해당 업무를 자동 갱신 + 히스토리 기록.

### 4.8 보안
- **2FA(TOTP)**: `User.totpSecret`/`totpEnabled`, `/settings/security`에서 설정, `POST /api/auth/2fa`(발급)/`/verify`(활성화)/`GET /check`(로그인 시 확인).
- **세션 관리**: `UserSession`(디바이스명/IP/최근 활동시각), `GET/DELETE /api/auth/sessions[/id]`로 내 세션 목록 조회 및 개별 종료.
- **감사 로그**: `AuditLog`(조직/사용자/액션/대상/상세 JSON), `/settings/audit`에서 조회.
- **보안 헤더**: 모든 응답에 `X-Content-Type-Options`/`X-Frame-Options`/`X-XSS-Protection`/`Referrer-Policy` 적용(`middleware.ts`).

### 4.9 플랫폼 관리 (SUPERADMIN)
- **조직 관리**(`/superadmin`, `/superadmin/[id]`): 조직 목록/상세 조회, plan(FREE/PRO/ENTERPRISE) 변경, 활성화/비활성화, 조직 삭제, 조직 상세에서 사용자 직접 추가.
- **플랜별 메뉴 권한**(`/superadmin/plan-config`, `SystemConfig.planFeatures`): 체크박스 매트릭스로 plan별 노출 메뉴(정보/신청/위키/업무/검색/통계/구글캘린더연동/외부연동)를 설정, `GET /api/plan-config`로 각 조직이 자신의 plan에 맞는 메뉴만 헤더에서 확인.
  - 기본값: `FREE`=[info,requests,wiki,tasks,search], `PRO`=+[stats,calendar_sync], `ENTERPRISE`=+[integrations]
- **플랫폼 통계**: `GET /api/superadmin/stats` — 전체 조직/사용자 현황 집계.

## 7. 비기능 요건

### 7.1 인증
NextAuth CredentialsProvider(bcryptjs) → JWT(id/email/name/role) → `middleware.ts`가 역할별 라우트 접근 제어. SUPERADMIN은 모든 보호 라우트 통과.

### 7.2 배포 (Railway)
- `npm run build` = `prisma generate && prisma db push --skip-generate && next build`(스키마 변경 시 별도 마이그레이션 명령 불필요).
- `postbuild`(`prisma/init.ts`)가 배포마다 `admin@admin.co.kr` SUPERADMIN 계정을 upsert.
- 헬스체크: `GET /api/health`.

### 7.3 환경변수

| 키 | 필수 | 설명 |
|---|---|---|
| `DATABASE_URL` | ✅ | PostgreSQL 연결 |
| `NEXTAUTH_SECRET` | ✅ | JWT 서명 시크릿 |
| `NEXTAUTH_URL` | ✅ | 서비스 베이스 URL |

| `GITHUB_WEBHOOK_SECRET` | ⬜ | GitHub webhook 서명 검증 |
