# High5 기능 정리

> 이 문서는 현재 시점에 구현되어 있는 모든 기능을 사용자/역할 관점에서 정리한 것이다.
> 기술적인 구조(스키마, API, 디렉터리)는 `docs/PROJECT_STRUCTURE.md`, 작업 이력은 `docs/HISTORY.md` 참고.
> **최종 업데이트** 2026-07-13

---

## 1. 계정 · 조직 구조

- **멀티테넌시**: 여러 회사(조직)가 한 서비스를 함께 쓰되, 조직별로 데이터가 완전히 분리된다.
- **조직별 로그인 URL**: `https://high5.up.railway.app/{조직slug}/login`으로 각 회사 전용 로그인 페이지 제공.
- **로그인 이후 URL도 조직별로 분리**: `/{slug}/dashboard`, `/{slug}/tasks` 등 — 다른 조직 URL로 잘못 접근하면 본인 조직 URL로 자동 교정.
- **역할 4단계**: SUPERADMIN(플랫폼 운영자) / ADMIN(조직 관리자) / LEADER(팀 리더) / WORKER(팀원).
- **로그아웃**: 조직 계정은 해당 조직 로그인 페이지로, SUPERADMIN은 시스템 로그인 페이지로 이동. 세션(30분 무활동) 만료 시에도 동일하게 처리.
- **비밀번호 변경**: 본인 인증 후 변경 가능(8자 이상).
- **로그인 브루트포스 방지**: 같은 계정으로 15분 내 5회 로그인 실패 시 15분 잠금.

## 2. 보안

- **2FA(TOTP OTP)**: 인증 앱(Google Authenticator 등) QR코드 등록, 로그인 시 6자리 코드 요구.
- **로그인 세션/디바이스 목록**: 내가 로그인한 기기 목록 조회, 원격 로그아웃.
- **감사 로그(Audit Log)**: 로그인, 계정 생성/삭제, 설정 변경 등 조직 전체 이벤트를 ADMIN이 `/settings/audit`에서 조회(날짜/유형 필터).
- **보안 헤더**: CSP, X-Frame-Options, Permissions-Policy, (운영환경) HSTS 등 브라우저 단 보호.
- **조직 데이터 격리**: 모든 API가 로그인한 사용자의 organizationId로 자동 범위 제한.

## 3. 업무 관리 (핵심 기능)

- **업무 등록/목록/상세/수정/삭제**: 제목·담당자·목표일·프로젝트·라벨(긴급/주말대응/비상)·비고(리치텍스트) 관리. RMS 번호(`[XXX-123]`) 자동 파싱.
- **그룹 업무 / 하위 업무**: 업무를 그룹으로 등록해 하위 업무를 여러 개 붙일 수 있음(구글시트처럼 펼치기/접기).
- **프로젝트별 커스텀 업무 상태**: 기본 5단계(배정/진행중/검수/QA/완료) 외에 프로젝트마다 단계·색상·순서를 자유롭게 정의 가능.
- **프로젝트별 커스텀 필드**: 노션식 자유 속성(텍스트/숫자/날짜/선택/체크박스/링크), 업무 목록에서 컬럼으로 표시·편집.
- **D-day 표시**: 목표일 기준 마감 임박(D-3 이내)/당일/초과를 색상 뱃지로 표시, 초과 업무는 행 강조.
- **업무 일괄처리**: 체크박스로 여러 업무 선택 후 상태/담당자 일괄 변경.
- **칸반 보드**: 프로젝트별 또는 전체 업무를 상태 컬럼으로 드래그해 이동.
- **자동 시간 카운터**: "진행중" 단계로 바뀌면 자동으로 작업 시간 측정 시작, 벗어나면 종료(업무별로 켜고 끌 수 있음).
- **작업자도 비고 수정 가능**: 담당 작업자는 본인이 맡은 업무의 "비고"를 직접 수정 가능(다른 필드는 여전히 관리자/리더 전용).
- **첨부파일**: 업무 등록/상세에서 파일 첨부(개당 5MB, 업무당 최대 5개), 다운로드/삭제.
- **댓글 & 답글 & @멘션**: 업무별 댓글, 답글(대댓글) 작성 가능(전 역할), `@이름`으로 멘션하면 자동완성 목록이 뜨고 멘션된 사람에게 알림 발송.
- **활동 히스토리**: 상태변경/담당자변경/제목변경/타이머 등 모든 변화가 시간순으로 기록.
- **GitHub PR 연동**: 업무에 연결한 PR이 머지되면 웹훅으로 자동 완료 처리.
- **CSV/엑셀 내보내기**: 업무 목록을 파일로 다운로드.

## 4. 캘린더 · 일정 관리

- **배포 캘린더**: 월별 캘린더에 업무 목표일 + 승인된 휴가를 함께 표시.
- **구글 캘린더 — 실시간 연동(OAuth, 권장)**: 개인 Google 계정을 연결하면 업무 등록/수정/삭제, 휴가 승인이 실시간으로 Google Calendar에 반영(단방향, High5 → Google).
- **구글 캘린더 — 구독 URL(대안)**: OAuth 없이도 iCal 구독 URL 발급 가능(반영까지 최대 몇 시간 소요).
- **마감일/휴가 알림 스케줄러**: 조직별로 설정한 "마감 알림 기준일"에 따라 마감 임박·초과 업무 담당자에게, 휴가 시작 하루 전 신청자에게 자동으로 인앱 알림 발송(서버 상시 프로세스에서 30분 주기 실행).
- **AI 주간 캘린더 요약**: 준비 중(버튼은 있으나 API 미연결 상태 — 안내 메시지만 표시).

## 5. 알림

- **인앱 알림 벨 아이콘**: 우하단 플로팅 버튼, 안읽음 개수 뱃지 표시. 클릭 시 최근 알림 목록 드롭다운(자동 전체 읽음 처리), 클릭 시 해당 업무로 이동.
- **토스트 팝업**: 새 알림 도착 시 화면 우상단에 5초간 팝업으로 노출.
- **알림 종류**: 담당자 배정/변경, 업무 상태 변경, 댓글 멘션, 신청 승인/반려, 공지 등록, 마감 임박, 휴가 리마인더.
- **외부 채널 연동(웹훅)**: Slack / 잔디(JANDI) / Microsoft Teams / 텔레그램 / 카카오톡 — 조직별로 채널 설정 후 업무 상태 변경 시 동시 발송, 테스트 발송 기능 제공(ADMIN 전용).

## 6. 협업

- **위키**: 프로젝트별 문서(마크다운 라이트: 굵게/기울임/목록), 소속 멤버만 조회/작성 가능. 전체 위키 통합검색(우하단 플로팅 버튼).
- **정보(FAQ)**: 조직 공지성 FAQ 콘텐츠(ADMIN 작성).
- **공지사항**: ADMIN/LEADER가 공지 등록 시 헤더 배너로 전 직원 노출 + 인앱 알림 발송. 게시중지/삭제 가능.
- **신청 & 전자결재**: 휴가/비품 신청, 담당 리더에게 결재 요청 → 승인/반려(반려 시 사유 필수). ADMIN/LEADER는 "전결"로 즉시 승인 + 공지 자동 등록 가능. 승인/반려 시 인앱 알림 발송.
- **내 자료**: 개인 보관용 문서(최대 3개, 위키와 동일한 에디터).
- **스티키 메모**: 화면 가장자리에 붙이는 개인 메모(최대 3개, 드래그로 순서 변경).

## 7. 조직 관리 (ADMIN)

- **팀원 관리**: 사용자 생성(임시 비밀번호 발급)/수정/비활성화, 소속 프로젝트·담당 리더(결재 라인) 지정.
- **프로젝트 관리**: 생성/수정/삭제, 멤버 관리, 프로젝트별 업무 상태·커스텀 필드 설정.
- **조직 설정**: 로고 업로드(200KB 이하), 헤더 표시명, 사업자번호/대표자명/대표번호/주소, 마감 알림 기준일.
- **데이터 백업**: 조직 전체 데이터(사용자·업무·프로젝트·댓글·신청·위키 등)를 JSON 파일로 다운로드(첨부파일 실제 내용은 제외, 메타데이터만 포함).
- **외부연동 설정**: Slack/잔디/Teams/텔레그램/카카오톡 채널별 Webhook 설정.
- **통계 & 리포트**: 월별 요약(총 업무/완료/완료율/총 공수), 작업자별 부하량, 월 이동 네비게이션, 엑셀 내보내기(월간요약 + 작업자별 시트).

## 8. 플랫폼 관리 (SUPERADMIN)

- **가입 현황 대시보드**: 전체 조직 수, 신규 가입, 전체 사용자 수, 플랜(FREE/PRO/ENTERPRISE) 분포, 최근 가입 조직 목록.
- **조직 관리**: 조직 생성/수정(사업자정보 포함)/삭제(연관 데이터 전체 cascade 삭제), 활성/비활성 전환, 플랜 변경.
- **조직별 사용자 추가**: 조직 상세에서 관리자 계정을 직접 생성.
- **플랜 기반 메뉴 권한 설정**: FREE/PRO/ENTERPRISE 플랜별로 어떤 메뉴(정보/신청/위키/업무/검색/통계/캘린더연동/외부연동)를 쓸 수 있는지 체크박스로 설정.

## 9. UI/UX

- **헤더 메뉴 구조**: 검색 / 업무(등록·목록·칸반·캘린더) / 협업(신청·위키·정보·공지사항) / 관리(프로젝트·팀원관리·통계) / 설정(조직설정·캘린더연동·외부연동·감사로그) / 마이페이지(내자료·비밀번호·보안설정·로그아웃). 각 메뉴는 역할·플랜에 맞게 자동으로 숨김.
- **전역 검색**: Ctrl+K(또는 헤더 검색 버튼)로 업무/위키 등 통합 검색.
- **모바일 반응형**: 업무 목록(테이블→카드 전환), 통계, 헤더 햄버거 메뉴 등 주요 화면 640px 이하 대응.
- **다크/라이트 테마 대응 컬러 시스템**(디자인 토큰 기반).
